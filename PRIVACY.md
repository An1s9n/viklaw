# Privacy Policy — viklaw

Last updated: 17.11.2026

viklaw is a private assistant built and operated by Pavel Anisimov for personal
household use. It is not offered to the public.

## What data is accessed
With the user's explicit consent via Google sign-in, viklaw may access the
Google account data needed for its features (for example, calendar events
or email). It only requests the permissions shown on the consent screen.

## How data is used
Data is used solely to provide the assistant's features to the account owner.
It is not sold, shared with third parties, or used for advertising.

## Storage
OAuth tokens and any cached data are stored on a private server controlled
by the operator. Data is processed by third-party AI model providers only as
needed to answer the user's requests.

## Google API Services
viklaw's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Revoking access
Access can be revoked at any time at https://myaccount.google.com/permissions.
